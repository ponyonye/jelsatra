### 2. CAKUPAN ASET
Lisensi dan hak cipta ini berlaku secara eksklusif untuk enam (6) berkas model 3D orisinal dalam format GLB yang berada di dalam direktori `public/models/`:

1. `komodo.glb` — Model 3D Komodo (*Varanus komodoensis*)
2. `orangutan_kalimantan.glb` — Model 3D Orangutan Kalimantan (*Pongo pygmaeus*)
3. `harimau_sumatra.glb` — Model 3D Harimau Sumatra (*Panthera tigris sumatrae*)
4. `badak_jawa.glb` — Model 3D Badak Jawa (*Rhinoceros sondaicus*)
5. `jalak_bali.glb` — Model 3D Jalak Bali (*Leucopsar rothschildi*)
6. `anoa_dataran_rendah.glb` — Model 3D Anoa Dataran Rendah (*Bubalus depressicornis*)
